Strict Rules
  • !Brand accent (#7C9BC4) is the ONLY accent color allowed. No other accent colors.
  • !Bullish green (#0ECB81) is EXCLUSIVE for profit/positive PnL ONLY. Never use for success states, checkmarks, or generic positive feedback.
  • !Bearish red (#F6465D) is EXCLUSIVE for loss/negative PnL ONLY. Never use for error states, warnings, or delete actions.
  • !ALL financial numbers (prices, PnL, percentages, volumes) MUST use JetBrains Mono with tabular-nums.
  • !No emoji icons anywhere. Tabler-style outline icons ONLY.
  • !Maximum 2-3 gradient colors per screen. No rainbow or multi-color gradients.
  • !No large radii on rectangular cards (max 13px). Pill radius (20px) ONLY for badges and pill-shaped elements.
  • !Never use white text directly on colored buttons (buy green, sell red). Use darker shade instead: #04150D on green.
  • !Background treatment: radial gradient glows at 8-12% opacity with drift animation (9-11s) + subtle grid pattern at 4-5% opacity.
  • !Card style: glass-morphism with 6px backdrop-blur + 0.5px border at rgba(255,255,255,0.025) background.

App Shell & Navigation

SHELL App Shell (AppShell)
Layout Wrapper

The main application frame that wraps every authenticated page. Provides consistent top navigation, bottom tab bar, and the slide-up More panel. The auth page uses a raw layout without this shell.

Top Navigation Bar
  • Fixed at top, 40px height, glass-header blur effect (16px blur + saturate)
  • Left side: VIXOR logo (22x22px gradient box) + "VIXOR" text label (13px bold)
  • Center/right: SOL price ticker with monospace font, bullish/bearish color based on 24h change — hidden on mobile, visible on desktop
  • Right side actions: "Deposit" button (navy gradient, hidden on mobile), Wallet Connect button (lazy-loaded), User avatar circle (26x26px, navigates to /profile), Bell notification icon (26x26px, with green dot for unread count, navigates to /notifications)
Bottom Tab Bar
  • Fixed at bottom, 52px height, glass background with top border
  • 5 items: Home (House icon), Analyze (Sun icon), Charts (Line chart icon), Signals (Signal icon), More (3-dots vertical icon)
  • Active tab: brand accent color (#7C9BC4) for icon + label, inactive: tertiary text color
  • Safe area padding respected for Telegram WebApp
More Panel (Slide-Up Sheet)
  • Full-height slide-up overlay triggered by the More button in bottom nav
  • Organized into 5 category groups, each with a section header:
  • AI Tools: AI Copilot, Alpha Signals, Whale Alerts, Predictions, Vision, Trackers
  • Trading: Trade Desk, Backtest, Journal, Daily Loop, Pulse
  • DeFi & Portfolio: Wallet, PnL Tracker, Bags, Portfolio, Perpetuals, Yield, Virtual Curve
  • Tools & Settings: Settings, Profile, Premium, Rewards, Referral, Notifications
  • Social: Communities, Discover
  • 2-column grid layout for items. Each item: icon + label text. Glass-card style rows.
  • Close button or tap-outside to dismiss
Background Treatment
  • Main background: #0B0D10 with subtle grid pattern overlay (4-5% opacity, 40x40px grid lines)
  • Radial gradient glow from brand accent at top-left area (8-12% opacity), with slow drift animation (9-11s cycle)
Onboarding Modal: Shown once to new users. 4-slide carousel with: (1) Welcome to VIXOR, (2) Drop a chart for AI analysis, (3) Trade with discipline, (4) Earn as you trade. "Get Started" button to dismiss. Glass-card slide containers, dot indicators, swipe navigation.

03 Analyze Chart
/analyze Built

Core AI feature page. User uploads a chart screenshot, selects a trading pair, and submits for SMC/ICT-based AI analysis. Supports drag-and-drop, file picker, camera capture, and clipboard paste. Costs points per analysis.

Visual Elements
  • Image Upload Area: Large dashed-border dropzone (border in border-subtle color, dashed). Centered upload icon (Tabler outline), "Drop chart here or tap to upload" instruction text. Supports: click to open file picker, drag-and-drop, camera button (mobile), paste from clipboard.
  • Camera Button: On mobile — hidden file input with capture="environment" attribute. Triggers native camera for photo capture.
  • Image Preview: When image is uploaded — full-width preview with rounded corners. "Remove" button (X icon) positioned at top-right corner of preview.
  • Pair Selector: Dropdown/Select component below the upload area. Options: BTC/USDT, ETH/USDT, SOL/USDT, XAU/USD, and other major pairs. Dark solid background, brand accent for selected state.
  • Submit Button: "Analyze Chart" — full-width button with brand accent color. Shows point cost next to label (e.g., "Analyze Chart — 10 pts"). Disabled state when no image selected. Loading spinner during analysis.
  • Points Balance: Small display showing current points balance. If insufficient points, show warning message.
States
  • No image uploaded — dropzone visible, submit disabled Empty
  • Image uploaded — preview shown, submit enabled Ready
  • Analysis in progress — submit shows loading spinner, button disabled Busy
  • Insufficient points — warning message shown, submit disabled Error
  • Analysis complete — navigates to /analysis/:id Success
URL Parameters: Can receive ?screenshot= (base64 image) and ?pair= (pre-selected pair) from other pages. This allows deep-linking from Signals or Discover pages directly into analysis with pre-filled data.

Detailed view of a completed AI chart analysis. Shows the original chart image, AI recommendation with confidence, key trading levels (Entry/SL/TP), order blocks, FVGs, liquidity zones, market structure analysis, and user notes. This is a rich, multi-section scrollable page.

Top Bar Actions

  • Analyst Report — Key Levels: Entry Price, Stop Loss, Take Profit. Each in a labeled row with monospace price values. SL in bearish color, TP in bullish color, Entry in primary text color.
  • Order Blocks: List of identified order block zones with price ranges. Glass-card rows.
  • FVGs (Fair Value Gaps): List of identified fair value gaps with price ranges. Glass-card rows.
  • Liquidity Zones: Identified liquidity pools with price levels. Glass-card rows.

States

  • Analysis not found / error — error message with "Go Back" action Error
  • Notes empty — "No notes yet. Add your first trading note." with Add button Empty

Shared Component Patterns

Reusable UI Patterns
Used across all pages

These patterns appear consistently across multiple pages. When designing in Google Stitch, maintain visual consistency by reusing these patterns.

PageLayout (Standard Page Wrapper)
  • Consistent structure: Header (title + optional badge + optional description) then Tabs (if applicable) then Loading Skeleton (during data fetch) then Content Area
  • Header title: large bold text, left-aligned
  • Badge: pill-shaped, positioned next to or below the title. Examples: "AI SIGNALS", "LIVE", "PORTFOLIO", "FUTURES"
StatsRow (Metrics Bar)
  • Horizontal row of 3-5 key metrics. Used on almost every data page.
  • Each metric: Label (small, secondary text, above) + Value (mono font, primary text, below)
  • Values that represent PnL or change: colored bullish/bearish
  • Scrollable horizontally on small screens
  • Separated by subtle vertical dividers or spacing
Glass Card
  • Background: rgba(255,255,255,0.025) with 6px backdrop-blur
  • Border: 0.5px solid rgba(255,255,255,0.06)
  • Border radius: 10-13px (medium to large, NOT pill)
  • Box shadow: 0 4px 24px -8px rgba(0,0,0,0.5)
  • Hover state: background transitions to #16181C (elevated)
  • Card enter animation: 0.45s fade + translate up
Badge / Pill
  • Pill shape only (20px radius). Small text (0.65-0.7rem), font-weight 600.
  • BUY badge: bullish green background (low opacity), bullish text
  • SELL badge: bearish red background (low opacity), bearish text
  • WAIT badge: neutral amber background (low opacity), amber text
  • Category badges: elevated background, secondary text, subtle border
  • Status badges (LIVE, AI, etc.): brand accent dark background (#232E3C), brand accent text
Empty State
  • Centered layout: large outline icon (Tabler style, tertiary color), Title text (secondary color), Description text (tertiary color), optional CTA button (outline or brand accent)
  • Generous vertical padding. No decorative elements beyond the icon.
Loading Skeleton
  • Shimmer animation (left-to-right gradient sweep)
  • Mimics the layout of real content (same dimensions, spacing)
  • Background: elevated color (#16181C). Rounded corners matching content cards.
Filter Tabs
  • Horizontal scrollable bar below the header/stats
  • Each tab: text label + optional count badge (small mono number)
  • Active tab: brand accent text color + bottom border or background highlight
  • Inactive tab: secondary text color, no decoration
Data Table / List Rows
  • Two variants: DataRow (single line) and DataRowTwoLine (two lines per row)
  • Table Header: uppercase small text, tertiary color, monospace for columns
  • Rows: subtle bottom border (border-subtle), press feedback (scale 0.98 on tap, 0.12s)
  • Numerical data: ALWAYS JetBrains Mono with tabular-nums
  • Horizontally scrollable on mobile with hidden scrollbar
Form Inputs
  • Background: solid card (#101317). Border: #1A1D22. Border radius: 7-10px.
  • Focus state: border color changes to brand accent (#7C9BC4), focus ring (#7C9BC466)
  • Text: primary color for input, secondary for placeholder
  • Labels: small, secondary color, above the input
  • Select/dropdown: same styling with chevron-down indicator
Buttons
  • Primary: brand accent background (#7C9BC4), dark text (#0B0D10). Press: scale(0.95) in 0.12s.
  • Buy button: bullish green background (#0ECB81), dark text (#04150D). Pulse glow animation (2.2s loop). NEVER white text.
  • Sell button: ghost/border style with bearish red border and text. NEVER white on red.
  • Outline: transparent background, border in border color, primary text.
  • Destructive: bearish red background (low opacity), bearish text. Only for delete/danger actions.
  • All buttons: border-radius 7-10px (NOT pill). Transition on hover and press.
Live Indicator
  • Small green dot (6px circle) with pulse animation (1.6s loop)
  • Used in "LIVE" badges, stats that update in real-time, monitoring indicators
  • Green color: #0ECB81 (but this is for live status, NOT for profit — acceptable use)
Progress Bar
  • Track: elevated background (#16181C), full width, 4-6px height, border-radius 3px
  • Fill: brand accent color (#7C9BC4), same height, same border-radius
  • For bullish contexts (e.g., win rate): fill in bullish green
  • Label: percentage text, mono font, positioned to the right or above the bar
