# Supabase CLI local state

`supabase/.temp/` contains machine-specific state generated by the Supabase CLI. It is intentionally excluded from version control and must not be used as the source of truth for the APP project reference.

## Preserve existing local files before updating this branch

This pull request changes only the Git branch. It does not access or delete files on developer machines. Before merging or pulling this change into an existing checkout, preserve any local CLI state if it is needed:

```sh
mkdir -p "$HOME/vixor-app-supabase-temp-backup"
cp -a supabase/.temp/. "$HOME/vixor-app-supabase-temp-backup/"
```

After updating the checkout, restore only files that are still needed locally. The directory remains ignored by Git. Do not commit its contents.
