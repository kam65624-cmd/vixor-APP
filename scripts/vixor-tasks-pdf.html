المُنجز
ما تم إنجازه في الجلسات السابقة
✓ إصلاح نقاط لا تُضاف (Auth Token Issue)
المشكلة:Supabase getUser(token) بيفشل بسبب global.headers.Authorization يتعارض مع الباراميتر الداخلي. كمان SUPABASE_PUBLISHABLE_KEY كان بيأخذ أولوية غلط على SUPABASE_ANON_KEY.
الحل:تقسيم Supabase client لعميلين منفصلين: واحد بدون global headers لـ getUser فقط، والتاني مع headers لاستعلامات RLS. تغيير أولوية env vars.
✓ إصلاح النقاط تظهر 0 في البار العلوي
المشكلة:Query key mismatch: rewards.tsx كان بيعمل invalidate لـ ["user-points"] بس الـ navbar بيستخدم ["user-points-nav"].
الحل:إضافة invalidate لكلا المفتاحين. تقليل staleTime من 60s لـ 30s وإضافة retry: 2.
✓ إصلاح GitHub CI (npm ci + eslint + prettier)
المشكلة:package-lock.json قديم وناقص باكيدج (zod, lru-cache, zugs). ESLint flat config مش بيتجاهل node_modules. Prettier formatting errors.
الحل:حذف وإعادة إنشاء lock file من الصفر. إضافة node_modules وكل المجلدات غير المصدرية لـ ignores. تغيير ESLint scope لـ src/ server/ فقط.
✓ إصلاح Redirect Loop في Rewards
المشكلة:خطأ Auth كان بيعمل redirect لـ /auth اللي بيعمل auto-signin ويرجع تاني = loop.
الحل:إزالة window.location.assign واستبداله برسالة "Session issue".
HOME الجلسة الحالية
إعادة تصميم الصفحة الرئيسية
تم إعداد تحليل مقارن شامل مع Binance و Coinbase و TradingView و Robinhood. التحليل حدد 10 مشاكل حرجة في الصفحة الرئيسية الحالية. كل مشكلة ليها مسبب واضح وحل مقترح. التصميم الجديد يقترح 10 أقسام متسلسلة تحل كل المشاكل.
HOME-P0 | لا يوجد سياق سوقي
أول حاجة شافها المتداول هي الأسعار
ليه مهم؟دخول على "صحراء" بدون أي سعر أو رقم = تجربة فاشلة. كل تطبيقات التداول الكبرى تعرض الأسعار مباشرة في الصفحة الرئيسية.
المسبب:الصفحة الحالية لا تعرض أي أسعار BTC/SOL/ETH أو أي market overview رغم إن endpoint market-overview.ts موجود في السيرفر.
الحل:إضافة Market Ticker Bar أفقي في أعلى الصفحة يعرض أسعار العملات الرئيسية مع نسبة التغير 24 ساعة.
التأثير:عالي جداً - أول انطباع للمستخدم
HOME-P1 | عرض المحفظة ضعيف
من "$0.00" رقم واحد لبطاقة احترافية
ليه مهم؟المحفظة هي أهم رقم للمتداول. عرض رقم واحد بدون equity chart أو إحصائيات = محتوى بلا قيمة. Binance و Robinhood بيعرضوا equity curve و stats فورية.
المسبب:getDashboardData بيرجع القيمة بس بدون winRate أو sharpeRatio أو equitySparkline أو recentTrades.
الحل:بطاقة Portfolio Hero: القيمة + mini equity chart + Win Rate + Trade Count + Sharpe Ratio. تحديث الـ API.
HOME-P2 | Quick Actions كثيرة
6 أزرار بتشتت دماغ المستخدم (Cognitive Overload)
ليه مهم؟أبحاث علمية بتقول إن المستخدم بيقدر يتعامل مع 3-4 خيارات كحد أقصى. 6 أزرار = تحميل معرفي زائد. كمان زر Charts بيودي لـ COMING SOON!
الحل:1 Primary CTA (Analyze Chart) + 2 Secondary (Discover, Copilot) بس.
HOME-P3 | AI CTA مدفون
أهم feature في التطبيق مخفي في card صغيرة
ليه مهم؟Analyze Chart هو المميزة التنافسية الأساسية لـ VIXOR. لو مش واضح وبارز = المستخدم مش هيشوفه ومش هيستخدمه.
الحل:زر Primary CTA كبير بـ gradient أخضر مع وصف واضح "AI-Powered SMC/ICT Analysis in Seconds".
HOME-P4 | لا يوجد إشارات فعّالة
المتداول مش شايف الفرص المتاحة
ليه مهم؟الإشارات هي أهم حاجة للتداول بعد الأسعار. بدون عرضها = المستخدم بيفوت صفقات محتملة.
المسبب:getDailySignals server function موجود بس الصفحة مش بتستخدمه.
الحل:بطاقة Active Signals تعرض أول 2 signal مع confidence و entry/tp/sl.
HOME-P5 | لا يوجد Watchlist
أي تداول بيبدأ بـ watchlist
ليه مهم؟Binance و TradingView بيعرضوا Watchlist في الصفحة الرئيسية. غيابها يعني المستخدم لازم يفتح Discover كل مرة.
الحل:بطاقة Watchlist مع sparkline وسعر وتغير وحجم تداول. لازم API جديد getWatchlist.
HOME-P6 | لا يوجد Market Sentiment
Fear & Greed و BTC Dominance أدوات أساسية
ليه مهم؟Binance بيعرض Fear & Greed Index. بدونها المستخدم مش عارف حالة السوق الكلية (bullish/bearish).
الحل:3 بطاقات: Fear & Greed Index + BTC Dominance + 24h Volume. جزء من getMarketOverview API.
HOME-P7 | إحصائيات غير مفيدة
"Points, Trades, Status" مش actionable
ليه مهم؟المستخدم محتاج بيانات تداولية مفيدة زي Win Rate و Sharpe Ratio مش بيانات عامة.
الحل:استبدال الإحصائيات ضمن Portfolio Hero Card.
HOME-P8 | تحية غير شخصية
"Welcome back, Trader" عاملة وباردة
ليه مهم؟Binance و Robinhood بيستخدموا تحية ذكية حسب الوقت + سياق السوق. التحية الشخصية بتخلي المستخدم يحس بالانتماء.
الحل:"Good Morning/Afternoon/Evening, [Name]" + التاريخ + حالة السوق + عدد الإشارات.
HOME-P9 | لا يوجد Recent Trades
آخر الصفقات فاضية دائماً
ليه مهم؟عرض آخر الصفقات بيمكّن المستخدم يتابع أدائه بدون ما يفتح Journal. Binance و Coinbase بيعملوا كده.
الحل:بطاقة تعرض آخر 3 صفقات مع pair و direction و PnL و time ago.
HOME-P10 | Layout مش متماسك
Padding 8px و cards متشابهة بدون visual hierarchy
ليه مهم؟صفحة ملزقة بـ padding 8px وكل cards بنفس الشكل واللون = مفيش فرق بين قسم وتاني = تجربة ممللة.
الحل:إعادة هيكلة بـ 10 أقسام متسلسلة مع padding 12-16px و visual hierarchy واضح وألوان مميزة لكل قسم.
