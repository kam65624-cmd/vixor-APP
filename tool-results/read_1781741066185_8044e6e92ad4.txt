   879→### 9.8 Notable schema patterns
   880→
   881→* **All tables use `SERIAL` or `BIGSERIAL` PRIMARY KEY** (no UUIDs in DB).
   882→* **Foreign keys** use `ON DELETE CASCADE` for ownership chains (user →
   883→  strategies → positions/trades).
   884→* **Soft migrations via `DO $$ ... END $$` blocks** that check
   885→  `information_schema.columns` before `ALTER TABLE ADD COLUMN` — so the same
   886→  `init.sql` is idempotent across upgrades.
   887→* **No row-level security (RLS)** — tenant isolation enforced at the
   888→  application layer via `user_id` filters in every query.
   889→* **No stored procedures, triggers, or views** — all logic in Python.
   890→* **JSONB** used liberally for flexible payloads
   891→  (`exchange_config`, `trading_config`, `indicator_config`,
   892→  `notification_config`, `request`, `result`, `progress`,
   893→  `request_summary`, `response_summary`, `reasons`, `scores`,
   894→  `indicators_snapshot`, `raw_result`, `outcome_tokens`, `key_factors`,
   895→  `entry_suggestion`, `chart_templates`, `notification_settings`).

   914→
   915→1. If `LLM_PROVIDER` env (or `llm.provider` config) set → use that
   916→   explicitly.
   917→2. Otherwise auto-detect by API key presence, priority order:
   918→   `DeepSeek > Grok > MiniMax > OpenAI > Google > OpenRouter`.
   919→3. If none configured → default to OpenRouter (will fail on first call with
   920→   a clear error message).

   922→### 10.3 Call paths
   923→
   924→* **OpenAI-compatible** (OpenAI, DeepSeek, Grok, OpenRouter, MiniMax, Custom):
   925→  standard `/chat/completions` POST with optional
   926→  `response_format={"type": "json_object"}` for JSON mode.
   927→* **Google Gemini**: bespoke `_call_google_gemini()` that converts OpenAI
   928→  message format to Gemini `contents`/`parts` format, with
   929→  `systemInstruction` for system messages and `responseMimeType:
   930→  "application/json"` for JSON mode.
   931→
   932→### 10.4 Error handling
   933→
   934→* Non-2xx responses produce detailed error messages with provider-specific
   935→  hints (e.g. OpenRouter 403 → "可能原因：API 密钥无效/过期、余额不足、或无
   936→  模型权限"; 404 → "可能原因：模型不可用或账户隐私/数据策略限制").
   937→* Empty content → `ValueError("Model X returned empty content")`.
   938→* Missing `choices` → `ValueError("API response is missing 'choices'")`.
   939→

   941→
   942→`_normalize_model_for_provider(model, provider)`:
   943→
   944→* If provider is OpenRouter → keep `vendor/model` format.
   945→* Otherwise → strip prefix (`openai/gpt-4o` → `gpt-4o`).
   946→* If prefix doesn't match the active provider → fall back to provider's
   947→  default model (prevents sending `gpt-4o` to DeepSeek).

   964→### 10.7 Self-calibration loop
   965→
   966→```
   967→qd_analysis_memory (validated rows)
   968→        │
   969→        ▼
   970→ReflectionService.run_verification_cycle()  (daily, background thread)
   971→        │ 1. Validate unvalidated rows older than 7 days
   972→        │    - Fetch current price for (market, symbol)
   973→        │    - Compute actual_return_pct = (current - price_at_analysis) / price_at_analysis × 100
   974→        │    - Set was_correct based on decision:
   975→        │       BUY correct if return > +2%
   976→        │       SELL correct if return < -2%
   977→        │       HOLD correct if |return| <= 5%
   978→        │    - Set validated_at = NOW()
   979→        ▼
   980→AICalibrationService.calibrate_market(market)
   981→        │ 2. For each candidate abs_threshold in [10,12,14,16,18,20,22,25,30]:
   982→        │    - For each validated row, predict decision from consensus_score:
   983→        │        score >= +thr → BUY
   984→        │        score <= -thr → SELL
   985→        │        else → HOLD
   986→        │    - Compute accuracy = correct_predictions / total_predictions
   987→        │ 3. Pick threshold with best accuracy (min 80 samples)
   988→        │ 4. INSERT into qd_ai_calibration (market, buy_threshold, sell_threshold, ...)
   989→        ▼
   990→FastAnalysisService reads qd_ai_calibration on next call
   991→        → uses tuned thresholds for BUY/SELL/HOLD decisions
   992→```

  1061→## 12. Auth & Security
  1062→
  1063→### 12.1 Auth pipelines (two parallel, never crossable)
  1064→
  1065→| Pipeline | Used by | Token format | Storage | Decorator |
  1066→|----------|---------|--------------|---------|-----------|
  1067→| Human JWT | Browser SPA, OAuth callbacks | `jwt.encode(payload, SECRET_KEY, HS256)`, 7-day expiry | Not stored server-side; `token_version` in DB enforces single-client | `@login_required`, `@admin_required` |
  1068→| Agent token | External AI agents, MCP server | `qd_agent_<urlsafe_32_bytes>` | SHA-256 hash in `qd_agent_tokens.token_hash` | `@agent_required(scope)` |
  1069→
  1070→A JWT is **never** accepted on `/api/agent/v1/*` and an agent token is
  1071→**never** accepted on `/api/*`. No accidental cross-use.
  1072→
  1073→### 12.2 JWT specifics
  1074→
  1075→* Algorithm: HS256.
  1076→* Payload: `exp` (7 days), `iat`, `sub` (username), `user_id`, `role`,
  1077→  `token_version`.
  1078→* **Single-client enforcement**: every login increments `qd_users.token_version`;
  1079→  JWT verification checks DB `token_version` matches the one in the token —
  1080→  mismatch → reject (kicks older sessions).
  1081→* Auto-regenerated `SECRET_KEY` if running in production with the default
  1082→  example value (defensive; `run.py` main()).
  1083→
  1084→### 12.3 OAuth2
  1085→
  1086→* Providers: Google, GitHub.
  1087→* CSRF state stored in `qd_oauth_states` (cross-worker safe — not in-memory).
  1088→* State TTL: 20 min (env: `OAUTH_STATE_TTL_MINUTES`).
  1089→* Auto-creates user on first OAuth login; links to existing user if email
  1090→  matches.
  1091→* Frontend redirect: PC hash mode (`/#/user/login`) or mobile history mode
  1092→  (preserves full path) — auto-detected by URL shape.
  1093→
  1094→### 12.4 Email verification & brute-force protection
  1095→
  1096→* 6-digit numeric code, 10-min expiry, max-5 attempts / 30-min lockout per
  1097→  email.
  1098→* `qd_login_attempts` tracks per-IP and per-account attempts.
  1099→* `qd_verification_codes.attempts` and `last_attempt_at` enforce code
  1100→  attempt limits.
  1101→
  1102→### 12.5 Credential encryption
  1103→
  1104→* `cryptography.fernet.Fernet` with key =
  1105→  `urlsafe_b64encode(hashlib.sha256(SECRET_KEY.encode()).digest())`.
  1106→* `encrypt_credential_blob(plaintext_json)` → Fernet-encrypted string for
  1107→  DB storage in `qd_exchange_credentials.encrypted_config`.
  1108→* `decrypt_credential_blob(stored)` → plaintext JSON; raises `ValueError`
  1109→  on wrong key (so rotating `SECRET_KEY` invalidates all stored credentials
  1110→  — must re-enter exchange API keys).
  1111→* API key hint (`api_key_hint` column) stores first 4 + last 4 chars for
  1112→  UI display.
  1113→* Secrets are masked in logs via `mask_secret()` (e.g.
  1114→  `ABCD...wxyz`).
  1115→
  1116→### 12.6 Rate limiting
  1117→
  1118→* **Per-token agent rate limit**: in-process sliding window,
  1119→  `rate_limit_per_min` per token (default 60). Returns HTTP 429 with
  1120→  `retriable: true` when exceeded.
  1121→* **Per-IP / per-account login throttling**: `qd_login_attempts` table.
  1122→* **Per-data-source rate limiters**: `RateLimiter` instances for
  1123→  eastmoney/tencent/akshare (min-interval + jitter).
  1124→* **Circuit breaker**: per-source failure tracking with cooldown (3min
  1125→  realtime, 5min akshare).
  1126→* **External API rate limits**: Finnhub (60/min), CCXT (built-in
  1127→  `enableRateLimit: true`).
  1128→
  1129→### 12.7 Code execution sandbox
  1130→
  1131→See §4.3 for the full safe_exec analysis. Key points:
  1132→
  1133→* Three-layer defense: regex blacklist → AST walk → restricted `__builtins__`.
  1134→* Whitelisted imports only: `numpy`, `pandas`, `math`, `json`, `datetime`,
  1135→  `time`, `collections`, `functools`, `itertools`, `statistics`, `decimal`,
  1136→  `fractions`, `operator`, `copy`.
  1137→* Cross-platform timeout (SIGALRM on Unix main thread, ctypes
  1138→  `PyThreadState_SetAsyncExc` elsewhere).
  1139→* Optional subprocess isolation via `multiprocessing.Process` with
  1140→  `RLIMIT_AS`.
  1141→* Fail-closed: AST parse failure → reject.
  1142→
  1143→### 12.8 Other security features
  1144→
  1145→* **SafeJSONProvider** in `app/__init__.py`: sanitizes NaN/Infinity to
  1146→  `null` in all JSON responses (RFC 8259 compliance).
  1147→* **CORS**: enabled globally via flask-cors (consider tightening for
  1148→  production).
  1149→* **Security headers**: `X-Frame-Options: SAMEORIGIN`,
  1150→  `X-Content-Type-Options: nosniff`, `X-XSS-Protection: 1; mode=block` in
  1151→  nginx.
  1152→* **Audit logs**: `qd_security_logs` (human auth events) +
  1153→  `qd_agent_audit` (every agent call).
  1154→* **Egress IP detection** for Binance IP whitelist debugging
  1155→  (`https://ifconfig.me/ip`).
